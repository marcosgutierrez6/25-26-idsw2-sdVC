# Estructura de carpetas obligatoria

```
├── .opencode/rules/       # Reglas del proyecto (este directorio)
├── contexto/              # Análisis y diseño del dominio
│   ├── casos-de-uso/      # Casos de uso (actores, contexto, detalle, prototipo)
│   └── diagramas/         # Diagramas UML (entidad, estados, objetos)
├── documents/             # Documentación adicional
├── images/                # Imágenes y SVGs generados
├── modelosUML/            # Códigos fuente .puml de diagramas UML
├── src/                   # Código fuente del sistema
├── QUE_HACE.md            # (inmutable tras primer commit)
├── README.md              # Presentación del sistema
├── conversation-log.md    # Log de sesiones
└── 2Think.md              # Criterios de evaluación internos
```

Ningún archivo debe estar fuera de estas carpetas (salvo los archivos raíz listados).
